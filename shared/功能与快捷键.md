# 功能与快捷键

筋斗云用稳定的功能语义连接两个平台。Windows 与 macOS 的按键不必完全相同，但应表达同一意图并符合平台习惯。用户本地配置可以覆盖默认应用和网址。

## 跨平台核心

| 功能语义 | Windows 默认 | macOS 默认 | 状态 | 说明 |
| --- | --- | --- | --- | --- |
| `toggle_window` | `Alt+Enter` | `Option+Enter` | 近似 | Windows 最大化/还原；macOS 最大化/恢复原尺寸 |
| `open_obsidian` | 见 Windows 快捷键总表 | `Option+O` | 支持 | 应用名称或路径可配置 |
| `open_chrome` | 见 Windows 快捷键总表 | `Option+C` | 支持 | 缺少应用时只禁用此项 |
| `open_wechat` | 见 Windows 快捷键总表 | `Option+W` | 支持 | Windows 应用名为微信，macOS 常见名称为 WeChat |
| `open_chatgpt` | 见 Windows 快捷键总表 | `Option+1` | 支持 | 使用系统默认浏览器或配置的 Chrome 入口 |
| `open_gemini` | 见 Windows 快捷键总表 | `Option+2` | 支持 | 打开网页入口 |
| `open_translate` | 见 Windows 快捷键总表 | `Option+T` | 支持 | 打开 Google 翻译 |
| `open_pouch` | 见 Windows 快捷键总表 | `Option+Shift+P` | 支持 | 从本地 Markdown 锦囊中选择并粘贴 |
| `media_previous` | Windows 媒体键映射 | `F7` | 支持 | 调用平台媒体控制 |
| `media_play_pause` | Windows 媒体键映射 | `F8` | 支持 | 调用平台媒体控制 |
| `media_next` | Windows 媒体键映射 | `F9` | 支持 | 调用平台媒体控制 |

## 平台差异

- Windows 公开版保留现有 AutoHotkey 功能集，包括更多应用入口、游戏模式、体检、日志和脚本热重载。
- macOS 第一版聚焦应用启动、窗口控制、网页、媒体和文本锦囊。
- Windows 的管理员启动、AppX AUMID、数字小键盘截图/录屏等能力暂不在 macOS 端模拟。
- macOS 的辅助功能权限必须由用户在系统设置中确认，智能体不得绕过。
- 某项标记为“近似”时，文档必须说明行为差异，不能声称完全一致。

Windows 完整现有映射见 `windows/文档/筋斗云-快捷键总表.html`。新增跨平台功能时，应先在本文件定义语义，再分别实现平台绑定。
